# PC-FX 팀 이노센트 한국어 패치

> [!WARNING]
> **v0.75는 전체 플레이 검증이 끝나지 않은 테스트 버전입니다.** 일부 구간의 실행과 패치 적용을 확인했지만, 모든 대화·영상·자막 타이밍을 끝까지 검증하지 않았습니다. 번역, 자막, 표시 및 진행 오류가 있을 수 있습니다. 원본 디스크와 저장 파일을 보관해 주세요.

일본판 **Team Innocent: The Point of No Return - G.C.P.O.SS**의 텍스트와 영상 음성을 한국어로 즐기기 위한 패치입니다. 게임의 원본 CUE/BIN 파일은 포함하지 않습니다.

**[v0.75 다운로드](https://github.com/OldManCraveGuitars-bit/PC-FX-Team-Innocent-Kr/releases/tag/v0.75)** · **[변경 사항](RELEASE_NOTES_v0.75.md)**

### 영상 건너뛰기

**게임 영상 재생 중 Ⅰ 버튼을 약 1.2초 동안 계속 누르면 다음 장면으로 넘어갑니다.** 해당 영상의 음성과 자막도 함께 종료됩니다.

- 짧게 누르거나 여러 번 나누어 누르는 입력은 누적하지 않습니다. 중간에 손을 떼면 처음부터 다시 셉니다.
- 오프닝과 인게임 영상에 적용합니다. 일반 대화의 초상화·배경·UI 표시와 영상 재생을 구분합니다.
- 버튼 번호는 **PC-FX 패드의 Ⅰ/Ⅱ 버튼** 기준입니다. 에뮬레이터에서 각각에 지정한 키나 패드 버튼을 사용하세요.

## v0.75에서 확인한 범위

- 신고된 `크레네에서 지켜볼게` 대사를 포함한 격납고의 연속 세 번 화자 전환에서, 음성 종료를 기다리지 않고 다음 대사와 모션이 시작되는 것을 실행 기록과 녹화로 확인했습니다. 기본 Mednafen에서도 같은 전환을 확인했습니다.
- 오프닝에서 짧은 입력 두 번으로는 영상이 유지되고, 길게 누르면 이전 영상과 자막이 종료되는 것을 확인했습니다.
- 인게임 격납고 진입 영상을 건너뛴 뒤 한국어 대화가 시작되는 것을 확인했습니다.
- 패치 결과가 검증한 로컬 빌드와 일치하는지 검사했습니다. 대사 1,371개와 영상 8개 장면의 자막 168개는 디스크에서 다시 읽어 검사했습니다.

**영상 건너뛰기는 영상으로 분류한 16개 자산을 대상으로 합니다. 16개 영상의 모든 진입 경로, 모든 대화 및 전체 플레이는 아직 검증하지 않았습니다.**

## 한글화 내용

- 영어 패치의 텍스트 변경 범위를 참고해 일본판 대사 1,371개와 메뉴·상태·아이템·엔딩 문구 등에 한글 초안을 적용했습니다. 원래 영어인 UI 문구는 그대로 둡니다.
- 시작 화면을 한글화하고 **PUSH RUN BUTTON**이 원판처럼 깜빡이도록 했습니다.
- 확인된 영상 장면 8개에 자막 168개를 넣었습니다. 자막은 영상에 인코딩하지 않고 별도 화면 레이어로 표시합니다. 일반 대사창에는 영상 자막을 띄우지 않습니다.
- 첫 오프닝 후반 문장과 음성 대사, 두 번째 오프닝 노래 자막을 포함합니다. 음성 번역과 노래 자막은 원음 재검수가 필요한 1차 초안입니다.
- 랑그릿사 FX 한국어 작업에서 사용한 글꼴과 12픽셀 자막 표시 규칙을 따릅니다. 실제 띄어쓰기에는 반각 공백을 사용합니다.
- 이전 버전에서 브리핑 배경의 크기·위치 오류, 영상 자막이 화면 위로 튀던 현상, `제~대로` 표기를 수정했습니다.

## 적용 방법 (Windows)

1. **[v0.75 릴리스](https://github.com/OldManCraveGuitars-bit/PC-FX-Team-Innocent-Kr/releases/tag/v0.75)**에서 **Team-Innocent-KR-Patcher.exe** 또는 전체 ZIP을 받습니다.
2. EXE를 실행하고 보유한 **일본판 원본 CUE 파일**을 선택합니다. 원본 BIN 14개는 CUE와 같은 폴더에 있어야 합니다.
3. 새 출력 폴더를 확인하고 **한국어 패치 적용**을 누릅니다. 완료되면 **완성 폴더 열기**로 결과를 확인합니다.
4. 완성 폴더의 **Team Innocent - The Point of No Return - G.C.P.O.SS (Japan).cue**를 PC-FX 에뮬레이터에서 엽니다.

**이전 패치본에 덧씌우지 말고 일본판 원본에 적용해 주세요.** EXE에는 패치 데이터가 포함되어 **Python 설치가 필요 없습니다.** 기본 창에서도 적용 버튼과 진행 기록이 보입니다. 원본 파일은 덮어쓰지 않습니다.

**업데이트 후에는 새 디스크를 처음부터 부팅해 주세요.** 이전 버전의 에뮬레이터 강제 저장 상태에는 이전 패치 코드가 남아 있을 수 있습니다. 게임 안에서 만든 저장 파일은 새로 부팅한 뒤 불러오세요.

Python 사용자는 ZIP의 **apply_patch.cmd**를 실행하거나 다음 명령을 사용할 수 있습니다.

    python apply_patch.py --source "원본 디스크 폴더" --output "새 출력 폴더"

원본 Track 02의 SHA-256이 **56931167724db296481606b6ba4d873097754faf4a59bd352a030dd8301028aa**인 덤프를 지원합니다. 적용 전후 해시를 검사합니다.

다른 패처를 사용하려면 원본 **Track 02 BIN**에 **patches/Team-Innocent-KR-v0.75.xdelta**를 적용한 뒤, 나머지 13개 트랙과 원본 CUE를 함께 사용하세요. 동봉한 Python 패처는 별도 xdelta 프로그램 없이 **tipatch**를 사용합니다.

## 감사와 출처

[Team Innocent 영어 패치 팀](https://github.com/DerekPascarella/TeamInnocent-EnglishPatchPCFX)의 작업은 한국어 패치 제작에 **큰 도움**이 됐습니다. 공개된 텍스트 변경 지점과 자료 덕분에 일본판 문구를 찾고 대조할 수 있었습니다. **Derek Pascarella (ateam), Elmer, EsperKnight, Filler, Eien ni Hen, Josh (hasnopants)를 비롯한 영어 패치 참여자 모두에게 진심으로 감사드립니다.** 이 한국어 패치는 영어 패치 팀의 공식 배포물이 아닙니다.

게임과 원본 그래픽의 권리는 각 권리자에게 있습니다. 패치에는 원본 게임 이미지 전체를 포함하지 않습니다. 글꼴은 Unifont 17.0.05와 Neo둥근모 1.601을 참고했으며 고지문은 [licenses](licenses)에 있습니다.
